How to get a Client ID (free, ~5 minutes, once)
  1. Open Google Cloud Console and create a project.
  2. APIs & Services → Library → enable Google Calendar API.
  3. OAuth consent screen → External → add your Gmail as a test user → add scope .../auth/calendar.app.created.
  4. Credentials → Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins add this page's address (for example https://gi-v.github.io).
  5. Copy the Client ID into the box above. Then press Connect Google Calendar.
