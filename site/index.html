How to install

Install the extension in four steps.

It isn't on the Chrome Web Store, so you load it from the folder. Takes under a minute.

  1. Open chrome://extensions in Chrome.
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and choose the extension folder.
  4. Pin the 📌 icon, then reload any tab that was already open.
